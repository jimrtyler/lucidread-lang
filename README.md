# LucidRead Language Packs

Translation data for [LucidRead](https://chromewebstore.google.com/detail/lucidread), a free reading accessibility Chrome extension.

## Data Sources

- **Wiktionary** — extracted via [Wiktextract](https://github.com/tatuylonen/wiktextract) from kaikki.org
- **TapSpeak AAC** — hand-curated core vocabulary (priority layer)
